## 3.67

A. e1 e2都是16字节 所以union也是16字节大小

B. 栈帧

s在%rsp，占16字节；y保存在%rsp+16。

%rsp+0：s.e2.x = y

%rsp+8：s.e2.next = &s

C.

```
void eval(union ele *up, long z) {
    *up->e2.next->e1.p = z - up->e2.x;
}
```

D.

process先保存y到栈，然后设s.e1.p = &y、s.e1.y = x，再设s.e2.next = &s，最后s.e2.x = y（覆盖 e1.p）。最终s偏移0为y，偏移8为&s。eval通过up->e2.next 得到&s，再->e1.p得到偏移0的值y，所以*... = z - up->e2.x，将z-y写入地址y。
